# mc-planner-refactored-v2

Minecraft 建築素材プランナー（`.mcstructure` / `.litematic` 入出力対応）。

## 開発

```bash
npm install
npm run dev    # localhost:3000
npx vitest run # テスト
```

---

## 🤖 Claude 起動チェックリスト

開発を始めるとき、Claude にまず以下の3ファイルを読ませる:

```
"C:\Users\maita\OneDrive\デスクトップ\　　　　　\AI\claude\🏠 ホーム.md"
"C:\Users\maita\OneDrive\デスクトップ\　　　　　\AI\claude\📌 注意事項.md"
"C:\Users\maita\OneDrive\デスクトップ\　　　　　\AI\claude\📊 進行状況.md"
```

> パスに全角スペースが含まれるため、シェルから扱う時は必ずダブルクォートで囲む。
